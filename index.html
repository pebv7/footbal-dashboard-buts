Par journée

La bande grise est l'intervalle où une journée tombe 19 fois sur 20 si rien ne change. Elle s'élargit quand la journée compte peu de matchs. Tant que les barres restent dedans, il n'y a pas de tendance à lire.

Qui est le plus extrême

Chaque ligne place les 8 compétitions entre leur minimum et leur maximum. Le point ambre est la compétition affichée ; touchez un point pour basculer dessus.

Toutes les compétitions

Le maximum de chaque colonne est en ambre, le minimum en bleu. Triez par un en-tête.

CompétitionMatchsMoyGG +0,5+1,5+2,5+3,51N2Buts 70ᵉ+

Attention aux effectifs : certaines compétitions n'ont que deux ou trois tours joués, donc leurs extrêmes bougeront beaucoup. La colonne « Matchs » donne le poids de chaque ligne.

Données : API ESPN, récupérée une fois par jour par un workflow GitHub Actions et embarquée dans ce fichier. Une copie des matchs joués est embarquée dans ce fichier pour qu'il fonctionne sans réseau ; « Mettre à jour » retélécharge la source, ce qui suppose un navigateur autorisé à sortir sur Internet. Le dépôt est tenu par des bénévoles, donc une journée peut arriver avec un jour ou deux de retard — la date de la dernière rencontre enregistrée est indiquée sous le titre. Seuls les matchs joués entrent dans les calculs. « GG » = les deux équipes marquent. « 1 / N / 2 » = victoire à domicile, nul, victoire à l'extérieur. Toutes les heures de coup d'envoi sont converties en heure de Paris, y compris pour l'Angleterre et le Portugal.
