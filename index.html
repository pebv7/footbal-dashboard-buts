Watch the sample sizes: some competitions have only two or three rounds played, so their extremes will swing a lot. The “Matches” column shows the weight of each row.

Data: ESPN API, fetched once a day by a GitHub Actions workflow and embedded in this file. A copy of completed matches is embedded so the page works offline; “Refresh” re-downloads the source, which needs a browser allowed to reach the internet. The repo is run by volunteers, so a matchday can arrive a day or two late — the date of the last recorded match is shown under the title. Only completed matches enter the calculations. “BTTS” = both teams to score. “1 / X / 2” = home win, draw, away win. All kick-off times are converted to Paris time, including England and Portugal.
